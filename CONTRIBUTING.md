# Contributing

Thanks for looking. This is a personal project, built and maintained for one household, and shared in case it's useful to someone else.

- **Issues are welcome:** bugs, questions, and ideas. I read them, though I can't promise a quick reply or a fix.
- **Pull requests may not be merged.** The app follows its owner's weekly routine closely, so changes that make sense for another household often don't fit this one. If you want something different, fork it — that's what the MIT license is for.
- **Keep personal data out.** This repo is public. Don't put real names, addresses, or your own data file in an issue or a pull request; use made-up examples.
